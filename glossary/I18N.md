# Obsidian プラグイン i18n / 日本語翻訳ガイドライン

このドキュメントは、Obsidianプラグインを日本語化する際の翻訳ルール・スタイルガイドを定めたものです。AI（Antigravity, Jules等）および開発者は、このルールに準拠して翻訳リソースを作成・保守してください。

---

## 1. 基本方針

1. **Obsidian公式日本語UIとの統一**:
   - `glossary/obsidian-ja.json` に定義された用語を最優先で使用します。
   - 例: "Vault" → "保管庫", "Ribbon" → "リボン", "Setting" → "設定", "Hotkeys" → "ホットキー"

2. **UI文言のトーン＆マナー**:
   - **ボタン・コマンド名**: 簡潔な動詞形または名詞形を使用（例: "Add note" → "ノートを追加", "Run" → "実行"）
   - **設定項目の名前（Setting Name）**: 体言止めまたは簡潔な名詞形（例: "Default folder" → "デフォルトフォルダ"）
   - **設定の説明文（Setting Description）**: 「〜します」「〜してください」などの丁寧な敬体（です・ます調）で統一。
   - **エラー / 警告 / 通知メッセージ**: わかりやすく原因と対策を伝える（例: "File not found" → "ファイルが見つかりません"）

3. **プレースホルダーの維持**:
   - `{name}`, `{0}`, `{{variable}}`, `%s` 等のプレースホルダーは**完全な形で保持**してください。プレースホルダー名を日本語に翻訳してはいけません。
   - 例: `"Exported {count} notes to {folder}"` → `"{folder} に {count} 件のノートをエクスポートしました"`

4. **カタカナ表記の長音ルール**:
   - 原則としてJIS規格（またはObsidian公式日本語訳）に準拠します。
   - 例: "Folder" → "フォルダ", "User" → "ユーザー", "Server" → "サーバー"

5. **プラグイン固有名称・構文記号**:
   - 独自の構文（マクロ名、変数タグ、スクリプト関数名など）は無理に日本語化せず、原文のまま維持します。
